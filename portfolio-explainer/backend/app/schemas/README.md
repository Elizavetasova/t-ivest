```
{
   "ticker": "SBER",
   "name": "Сбербанк",
   "quantity": 100,
   "currency": "RUB",
   "current_price": 250,
   "previous_price": 260,
   "market_value": 25000,
   "weight_percent": 50,
   "change_percent": -3.85,
   "contribution_percent": -1.92
 }
```

- `change_percent` — изменение цены актива.

- `weight_percent` — доля позиции в портфеле.

- `contribution_percent` — вклад позиции в изменение портфеля, выраженный в процентных пунктах.

Для простого портфеля без сделок внутри анализируемого периода:

\[
Contribution_i = Weight_i \times Return_i
\]

Если вес составляет 50%, а изменение цены −3,85%, вклад равен примерно −1,92 процентного пункта.

В дальнейшем нужно учитывать сделки, денежные остатки, комиссии и корпоративные события. Для MVP допустимо ограничить анализ портфелем без операций в течение выбранного периода.

Замечание: в production финансовые значения лучше хранить с точностью `Decimal`, а не `float`. В демонстрационном MVP `float` проще, но округление должно происходить только при отображении.

# Почему разделяем main_factors и possible_causes
Это принципиально важно.

`main_factors` — математически подтверждённые факторы изменения портфеля.

Например:
Акция SBER снизилась на 4%, что внесло −1,2 процентного пункта в результат портфеля.

`possible_causes` — возможные объяснения движения:
В день снижения появилась новость о финансовых результатах компании.

Первое является вычислением.

Второе является гипотезой.

Так мы не позволяем модели смешивать финансовые факты и предположения.
